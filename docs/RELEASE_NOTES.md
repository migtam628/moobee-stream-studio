# MooBee Stream Studio Alpha 0.3.0 — native foundation

A development milestone for the standalone capture pipeline. This is not a complete broadcasting release.

- Independent scene control and local API.
- Mac/Windows native display enumeration and screenshot preview code.
- Local test alerts and overlays.
- No external OBS/Streamlabs connection or credentials.
- Recording, streaming, audio capture and compositor are *not implemented*.
- Mac/Windows native build and real-device permission tests must pass before release.
